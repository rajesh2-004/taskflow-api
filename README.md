# TaskFlow API

TaskFlow is a secure task management
application built using Python and FastAPI.

## Features

- User Registration
- User Authentication
- Role-Based Authorization
- Task Management
- REST APIs

## Technologies

- Python
- FastAPI
- PostgreSQL
- Git
- Docker
